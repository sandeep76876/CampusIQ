# CampusIQ Automated Testing Suite

This directory contains test suites for all platform tiers:
- `unit/`: Component-level and function-level isolated tests (Frontend, Backend, AI service).
- `integration/`: Supertest and HTTP integration tests across services.
- `blackbox/`: Requirements-based acceptance and functional test criteria.
- `whitebox/`: Path-coverage and internal branch test specifications.
- `e2e/`: Browser end-to-end user journey tests.
